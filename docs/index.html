A notebook for FieldWorks, with your examples alive in it

Write grammar notes, field notes and drafts in tabs and folders. Paste lines from FLEx and they become real interlinear examples, read straight from your project, so they show your current analysis. Mark them up, collect them, and send them back to FLEx as a text.

Windows 10 or 11, 64-bit. Reads FieldWorks 9 projects on the same computer; never changes them.

From FLEx to your notes, and back

Everything an example shows comes from your FLEx project as it is now. Edit an analysis in FLEx, click ↻, and the example in your notes follows.

1

Paste from FLEx

Copy interlinear lines in FLEx (the Gloss or Print view) and paste them into a note. FLEx Scratchpad finds the segment in your project and draws the example: words, morphemes, glosses, categories and the free translation. Or pick a text and its segments, or a lexical entry, from the FLEx object button.

2

Mark it up

Click a word to highlight, bold or underline it, a morpheme or a few letters, in any colour. Number your examples, put them in tables, write around them. Headings fold their sections away while you work on something else.

3

Collect and export

Gather the examples of a construction into an example collection, sort them into groups, add a note to each. Export it as one FLEx text, with a short audio clip for every line, and analyse the examples together in FLEx, in the Text Chart for instance.

Made for the way linguists keep notes

A plain notebook first, so it stays out of your way, with FieldWorks built in where it matters.

Live from your project

Examples and entries are read from FLEx every time they are shown. Your project is only ever opened for reading.

Your notes are files

Every note is a Markdown file in an ordinary folder, readable without the program and easy to back up. Nothing is ever deleted: removed notes go to the notebook's trash.

Tables and charts

Paradigm tables with merged cells and examples inside them, pasted from Excel or Word, and simple charts, all saved with the note.

Hear the example

When a text is time-aligned, each example plays its own stretch of the recording. Clips are cut and kept with the notebook, so they still play when the recording is somewhere else.

Works offline

Everything it needs comes in the download, including the audio tools. It never needs the internet and runs no server of any kind.

Every script

Unicode throughout, right-to-left text laid out right to left, each writing system in its own FLEx font, and search that can ignore diacritics.

Install in a minute

Both downloads are the same program. The installer adds it to the Start menu; the zip runs from wherever you unzip it, a USB stick included.

Installer

  1. Download FLEx-Scratchpad-Setup and run it. It installs for your user account and needs no administrator rights.
  2. It isn't signed yet, so Windows may say “Windows protected your PC”: choose More info, then Run anyway.
  3. Start FLEx Scratchpad from the Start menu, open Settings ⚙ and pick your FLEx project.

A newer Setup upgrades in place and keeps your notebooks. To remove it: Settings › Apps › FLEx Scratchpad › Uninstall; your notebooks stay where they are.

⬇ Windows installer

What it needs

  • Windows 10 or 11, 64-bit.
  • FieldWorks 9 on the same computer, to read a FLEx project. Without it you can still open a .flextext file or try the built-in demo.
  • Microsoft Edge WebView2, which Windows 11 has. The installer tells you if this computer needs it.

If something does not work, run FLEx Scratchpad.exe --selftest report.json in the program's folder and attach the report to an issue.
